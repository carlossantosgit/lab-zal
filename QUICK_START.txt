# ⚡ QUICK GUIDE - 10 MINUTOS

```
┌─────────────────────────────────────────────────────────────┐
│  DEPLOY PROMETHEUS → ZABBIX SYNC EM NOVO SERVIDOR           │
│  Tempo: 10 minutos | Complexidade: Baixa                    │
└─────────────────────────────────────────────────────────────┘
```

---

## 👉 EXECUTE ISTO NA ORDEM:

```bash
# 1️⃣  CLONAR
git clone https://github.com/carlossantosgit/lab-zal.git
cd lab-zal/production

# 2️⃣  SETUP PYTHON
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3️⃣  EDITAR CREDENCIAIS
nano config.py
# Alterar 6 valores: PROMETHEUS_URL, PROMETHEUS_USER, PROMETHEUS_PASS, ZABBIX_API_URL, ZABBIX_USER, ZABBIX_PASSWORD

# 4️⃣  VALIDAR
python3 validate.py
# Resultado esperado: ✅ VALIDAÇÃO OK

# 5️⃣  SINCRONIZAR
python3 sync_prometheus.py --all

# 6️⃣  AUTOMAÇÃO (OPCIONAL - sincronizar cada hora)
crontab -e
# Adicionar: 0 * * * * cd /home/usuario/lab-zal/production && source venv/bin/activate && python3 sync_prometheus.py --all >> /var/log/prometheus-zabbix-sync.log 2>&1
```

---

## 📍 ONDE EDITAR CREDENCIAIS

Arquivo: `config.py`

```python
PROMETHEUS_URL = "https://seu-prometheus"      ← EDITAR
PROMETHEUS_USER = "usuario"                     ← EDITAR
PROMETHEUS_PASS = "senha"                       ← EDITAR

ZABBIX_API_URL = "http://seu-zabbix:8080/api_jsonrpc.php"  ← EDITAR
ZABBIX_USER = "Admin"                           ← EDITAR
ZABBIX_PASSWORD = "senha"                       ← EDITAR
```

## 🆘 SE DER ERRO

| Erro | Solução |
|------|---------|
| "Prometheus não acessível" | Verificar URL, user, password em config.py |
| "Zabbix não acessível" | Verificar URL, firewall, conectividade |
| "Login falhou" | Revisar ZABBIX_USER e ZABBIX_PASSWORD |
| "requests não instalado" | `pip install -r requirements.txt` |

## 📊 COMANDOS FREQUENTES

```bash
# Antes de TUDO
source venv/bin/activate

# Validar
python3 validate.py

# Ver hosts
python3 sync_prometheus.py --list

# Sincronizar
python3 sync_prometheus.py --all

# Sincronizar 1 host
python3 sync_prometheus.py --host seu-host

# Detalhado
python3 sync_prometheus.py --all --verbose

# Ver logs
tail -f /var/log/prometheus-zabbix-sync.log
```
